발컨 던전 레벨업 가이드 (포에버판) 1.1.4 (BalCon)
==========================================

던전을 목표로 레벨업하는 Guidelime 가이드입니다.
던전에 갈 레벨이 되면 그 던전을 먼저 다녀오고, 다음 던전 레벨이 될 때까지 효율 좋은 지역 퀘스트만 합니다.
1.1.0 부터 60레벨까지 이어집니다.

■ 1.1.4 — 로데론의 폐허 "새로운 역병" 선행 퀘스트 · 12-20 동선 다시 짜기
  - "새로운 역병"(시어도어 그리프스)은 "죽음의 비법" 연계 3단계를 끝내야 받을 수 있어서 동선에 넣음 (게임에서 확인).
    렌퍼럴(공동묘지): 불곰 심장·땅거미 점액 → 파라넬(언더시티) → 장작나무 마을 베랄드의 책장 → 렌퍼럴 →
    로더미어 호숫가 이끼 2종 + 굳어진 종양(썩은지느러미멀록, 드롭률 약 5%) → 파라넬 → 시어도어.
  - 순서 변경: 성난불길 → (언더시티·은빛소나무 숲) 폐허 선행 퀘스트로 16레벨 → 로데론의 폐허 →
    (불모의 땅·썬더 블러프) 통곡의 동굴 선행 퀘스트 → 통곡의 동굴. 예상 레벨: 폐허 16.0 → 18.2 · 통곡 19.2 → 20.9.

■ 1.1.3 — 12레벨에 1-12 가이드 마치기 · 로데론의 폐허 선행 퀘스트
  - 1-12 시작 지역 가이드: 12레벨이 되면 안내 창이 뜹니다. "던전 가이드로 넘어가기"를 누르면 화면을 다시 불러오며
    12-20 던전 가이드로 바로 넘어갑니다. 창에는 이 가이드에 남은 퀘스트를 안 했을 때 받지 못하는 평판(세력별, 지금 평판과 함께)과
    남은 직업 퀘스트가 경고로 나옵니다. "이 가이드 계속하기"를 고르면 다시 묻지 않고, /발컨 12 로 창을 다시 띄웁니다.
  - 12-20 가이드: 1-12 를 중간에 마치고 넘어온 경우의 합류 안내 추가, 크로스로드 비행 지점·귀환 장소 단계를 모든 종족에게 표시.
  - 로데론의 폐허: 죽음경비병 크리스토프의 "라스마엘의 격노"는 바로 옆 죽음의경비병 리니아의 "후방 경비" 두 단계
    (좀비·영혼 처치 → 정예 너덜토막의 심장)를 먼저 끝내야 받을 수 있어서 그 단계를 추가.
  - 로데론의 폐허 "새로운 역병": 선행 퀘스트("죽음의 비법" 연계)가 있다는 제보가 있어 확인 중 — 지금은 선택 단계로 표시.

■ 1.1.2 — 사제·흑마법사: 20레벨 무렵 검은심연의 나락 마법봉 선택 단계
  - 20-30 가이드 시작(썬더 블러프 보고 직후)에 사제·흑마법사에게만 보이는 선택 단계 추가.
    도와줄 높은 레벨 파티원이 있으면 검은심연의 나락에서 "검은심연의 음모"만 하고 썬더 블러프 바샤나 룬토템에게 보고해
    보상 마법봉 "묘비의 홀"을 받습니다. 24~25 지역 퀘스트를 이 마법봉으로 합니다.
  - 다른 검은심연 퀘스트는 원래대로 24~25 검은심연 때 합니다. 이미 끝낸 "검은심연의 음모" 단계는 그때 저절로 넘어갑니다.
  - 도와줄 사람이 없으면 선택 단계를 건너뛰면 됩니다. 마법사는 광역 사냥을 하므로 넣지 않았습니다.

■ 1.1.1 — 가이드 줄 끝에 표시 추가
  - 퀘스트 수락·완료 줄 끝에 이런 표시가 붙습니다 (게임 안 가이드 창에 그대로 보임):

    ★보상 연계 — ★보상 퀘스트로 이어지는 앞 단계
    ◆던전 선행(던전 이름) — 그 던전 퀘스트를 받으려면 먼저 해야 하는 퀘스트
    ◆던전 연계(던전 이름) — 던전 퀘스트를 끝낸 뒤 이어지는 퀘스트
  - 1-12 시작 지역부터 45-60 까지 모든 가이드에 적용.
  - 영어판: 영어 게임 글꼴에 없을 수 있는 기호(★ ▶ → ※ ─)를 * >> -> ! = 로 바꿈. 영어판 표시는 *Reward · *Reward chain · Dungeon prereq (…) · Dungeon chain (…).
